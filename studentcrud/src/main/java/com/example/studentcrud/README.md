# Spring Boot CRUD Application

REST-based CRUD application for managing Student records.

## Technologies
- Spring Boot
- Spring Data JPA
- PostgreSQL
- REST API

## Endpoints
- POST /students
- GET /students
- GET /students/{id}
- PUT /students/{id}
- DELETE /students/{id}

## How to Run
1. Configure database in `application.properties`
2. Run `SpringBootCrudApplication.java` in IntelliJ
