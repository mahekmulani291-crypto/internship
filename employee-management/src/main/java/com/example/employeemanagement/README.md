# Employee Management System (Spring Boot)

This project is a Spring Boot REST API for managing employee data.
It supports CRUD operations using Spring Data JPA.

## Features
- Add Employee
- Get All Employees
- Get Employee by ID
- Update Employee
- Delete Employee

## Technologies Used
- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

## How to Run
1. Configure database details in application.properties
2. Run the Spring Boot application
3. Test APIs using Postman
